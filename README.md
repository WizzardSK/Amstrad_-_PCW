# Amstrad_-_PCW

Thumbnails for Amstrad PCW software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `pcw` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/), the ones taken at 736x272 doubled vertically like the rest (the PCW's pixels are twice as tall as wide). Snaps and titles that are all black are left out.
